Informativa sulla privacy

Quiet Ledger · aggiornata il 23 novembre 2026

In breve

Quiet Ledger non raccoglie, non riceve e non vende alcun dato. Non esiste un server dell'app: tutto ciò che inserisci resta sui tuoi dispositivi e, se attivi la sincronizzazione, nel tuo Google Drive, solo in forma cifrata.

Quali dati tratta l'app

Le spese, le entrate, gli abbonamenti, i saldi e gli obiettivi di risparmio che inserisci o importi (anche da file Excel, CSV o dagli estratti conto PDF della banca, letti solo sul tuo PC). Questi dati sono salvati sul dispositivo in un archivio cifrato (AES-256-GCM):

  • sul PC, apribile solo con il tuo PIN su quel PC o con il tuo codice di recupero;
  • sull'iPhone, nella memoria del browser, apribile solo con Face ID (passkey) o con la password che scegli.

Google Drive

Se attivi la sincronizzazione tra PC e telefono, l'app chiede l'accesso al tuo Google Drive con il solo permesso drive.appdata: una cartella nascosta riservata all'app. L'app non può vedere, leggere o modificare gli altri file del tuo Drive.

  • In quella cartella vengono scritti solo file cifrati sul tuo dispositivo, prima dell'invio. Né Google né l'autore dell'app possono leggerne il contenuto.
  • L'accesso a Google avviene sulle pagine di Google: l'app non vede mai la tua password di Google.
  • Sul PC il token di accesso a Google è conservato dentro l'archivio cifrato. Sull'iPhone il token vale circa un'ora, è salvato solo nella memoria del browser e permette di usare soltanto la cartella nascosta dell'app.
  • L'uso delle informazioni ricevute dalle API di Google rispetta le norme sui dati utente dei servizi API di Google, inclusi i requisiti di utilizzo limitato.

Condivisione con terzi

Nessuna. L'app non contiene pubblicità, strumenti di analisi o di tracciamento, e non trasmette dati all'autore né a terzi.

Questo sito e la web app sono ospitati da GitHub Pages: come ogni servizio di hosting, GitHub può registrare l'indirizzo IP di chi visita le pagine, per motivi tecnici e di sicurezza, secondo la propria informativa. I dati delle tue spese non passano mai da GitHub.

Conservazione e cancellazione

I dati restano finché non li elimini. Puoi cancellare tutte le spese dalle Impostazioni dell'app sul PC e l'intero archivio dall'iPhone (Impostazioni della web app). Disattivando la sincronizzazione puoi eliminare anche i file cifrati da Google Drive e revocare l'accesso. In alternativa puoi revocarlo da myaccount.google.com/permissions.
